# EVO Research

## Objective

Resolve external uncertainty with current evidence instead of model memory.

## Method

Start from the concrete decision/question and repository constraints. Search current primary sources first: official documentation, standards, upstream repositories/releases, vendor guidance, authoritative papers, and original issue/change records. Use community discussion mainly for experience signals, not as the sole authority for hard facts.

Compare only real viable alternatives. For each, capture compatibility, maintenance cost, migration burden, operational risk, lock-in, maturity, and evidence quality. State publication/version dates when freshness matters.

## Repository result

If the research is likely to matter beyond the current chat, write a concise cited Markdown research note in the repository's existing research/docs location. Separate:

- verified external facts;
- repository-specific implications;
- recommendation;
- unresolved uncertainty.

Research informs a decision; it does not silently become one. Material trade-offs still require the responsible human or repository authority.
