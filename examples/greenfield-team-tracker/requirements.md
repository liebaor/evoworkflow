# Greenfield experiment: team task tracker

Build a Chinese-language, self-hosted web application for a team of at most 20 people. It needs projects, tasks, comments, file attachments, basic role-based access, CSV import/export, and Docker deployment on one server. The team can maintain Node.js or Python. Prefer a mature open-source foundation when its license, extension model, and operating cost fit; do not implement before a human selects the foundation.
