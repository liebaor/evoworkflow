# RuoYi Brownfield Scenario

This scenario is used to evaluate `evo-init` on a mature RuoYi-style application.

A successful initialization should discover repository-specific evidence for concerns such as:

- standard response envelope;
- pagination flow;
- permission checks;
- audit/log annotations;
- Excel/import-export utilities;
- representative CRUD controller/service/mapper flow;
- frontend request/table/form conventions;
- existing test/build commands.

The expected output is not a RuoYi tutorial. It is a repository-specific map linking each concern to the actual capability/reference in the fixture repository with confidence and observation metadata.

A downstream planning or coding workflow should be able to read the standing agent instructions, find the relevant `.evo/` entry, inspect the real reference, and avoid inventing parallel infrastructure.
